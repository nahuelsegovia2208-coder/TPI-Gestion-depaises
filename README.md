# Gestión de Datos de Países en Python

## Descripción
Aplicación de consola para administrar países mediante listas, diccionarios, funciones y un archivo CSV.

## Requisitos
- Python 3.x
- No requiere instalar bibliotecas externas.

## Archivos
- `main.py`: código fuente del programa.
- `paises.csv`: dataset inicial de países.

## Cómo ejecutar
1. Colocar `main.py` y `paises.csv` en la misma carpeta.
2. Abrir una terminal en esa carpeta.
3. Ejecutar: `python main.py`

## Opciones del menú
1. Mostrar todos los países.
2. Agregar un país.
3. Actualizar población y superficie.
4. Buscar por nombre completo o parcial.
5. Filtrar por continente, rango de población o rango de superficie.
6. Ordenar por nombre, población o superficie.
7. Mostrar estadísticas.
0. Guardar y salir.

## Almacenamiento
Los cambios realizados al agregar o actualizar países se guardan automáticamente en `paises.csv`, que puede abrirse con Excel. Al abrirlo en Excel se verán los mismos datos guardados por el programa. Se recomienda cerrar Excel antes de ejecutar el programa para evitar conflictos de bloqueo del archivo.
